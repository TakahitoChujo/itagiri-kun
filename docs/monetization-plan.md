## 1. エグゼクティブサマリー

### 基本方針

「板取りくん」のマネタイズは **倫理的フリーミアム** モデルを採用する。ユーザーに十分な無料体験を提供しつつ、プレミアム機能の価値を自然に理解してもらい、自発的な購入意欲を喚起する設計とする。

| 項目 | 内容 |
|------|------|
| 収益モデル | 無料（広告あり）+ プレミアム（買い切り、広告なし） |
| プロトタイプ段階 | プレミアム機能も無料開放（広告は表示） |
| 主要収益源 | (1) プレミアム買い切り課金 (2) AdMob バナー広告 |
| Dark Pattern | 使用しない。倫理的な範囲で行動心理学を活用 |
| 設計思想 | 無料でも十分に使えるが、プレミアムで「もっと便利」になる |

### 想定収益モデル

```
月間収益 = (DAU × 広告表示回数 × eCPM / 1000) + (新規DL × 課金転換率 × 課金単価)

目標値（リリース6ヶ月後）:
  DAU: 500人
  広告収益: 500 × 3回 × ¥50/1000 = ¥75/日 ≒ ¥2,250/月
  課金収益: 3,000DL/月 × 3% × ¥980 = ¥88,200/月
  合計: 約 ¥90,000/月
```

## 2. ターゲットユーザーの行動分析

### 2.1 ユーザーペルソナ

| ペルソナ | 特徴 | 課金確率 | アプリの使い方 |
|----------|------|----------|----------------|
| **A. 週末DIYer**（最多層） | 月1-2回DIY、ホームセンターでカットサービス利用 | 低〜中 | 不定期にプロジェクト単位で使用 |
| **B. DIY入門者** | 初めてのDIY、失敗したくない | 中 | 材料購入前に1回きりの場合も |
| **C. 本格DIYer** | 週1以上、電動工具所持、複数プロジェクト並行 | 高 | 日常的に使用、PDF出力需要高 |
| **D. プロ・業者** | 仕事として使用、効率重視 | 最高 | 業務ツールとして毎日使用 |

### 2.2 行動パターンの分析

DIYユーザーのアプリ利用には **明確なトリガーポイント** がある。

```
[認知] ホームセンターに行く前日 or 当日
  ↓
[検索] 「木材 カット 計算」「端材 最小化」でストア検索
  ↓
[DL] アプリインストール（この時点で強い利用意図あり）
  ↓
[初回利用] 1Dカット計算を試す
  ↓  ← ★ この体験の質が課金転換の鍵
[価値認識] 「端材が減る！」「何本買えばいいか分かった！」
  ↓
[2回目利用] 別のプロジェクトで再利用 → リテンション確立
  ↓
[制限遭遇] 2D合板やPDF出力が必要になる → 課金転換ポイント
```

**重要な心理学的洞察**: DIYユーザーは「木材購入前の計算」というタイミングで利用する。これは **損失回避（Loss Aversion）** が最も働く瞬間である。「計算を間違えたら木材代が無駄になる」という恐怖が、アプリの価値を最大化する。

### 2.3 支払い意思額（WTP）の推定

日本のDIYユーザーの文脈における参照価格:

| 参照対象 | 金額 |
|----------|------|
| 2x4材 6フィート（1820mm）1本 | ¥300〜500 |
| ホームセンターのカットサービス（1カット） | ¥30〜50 |
| 木材の無駄買い（1本余計に購入） | ¥300〜800 |
| 類似DIYアプリ（CutList Optimizer等） | ¥0〜¥1,200 |
| コーヒー1杯 | ¥300〜500 |

**アンカリング効果の活用**: ユーザーが「木材1本の無駄を防げる」と認識すれば、¥300〜800の節約に対してアプリ代¥980は合理的に見える。**「1回の利用で元が取れる」** という訴求が最も効果的。

## 3. プラン構成と機能振り分け

### 3.1 設計原則

フリーミアムの機能振り分けには以下の原則を適用する。

| 原則 | 説明 | 根拠 |
|------|------|------|
| **コア価値は無料で提供** | 1Dカット最適化は無料で制限なく使える | 無料ユーザーの満足度がクチコミを生む |
| **生産性向上を有料化** | 時間節約・効率化に直結する機能を有料に | 「便利さの対価」は受容されやすい |
| **制限は量ではなく種類で** | 回数制限や部材数制限は設けない | 回数制限は怒りを生む（リアクタンス理論） |
| **出力系を有料化** | PDF出力など外部連携を有料に | 内部利用は無料、外部出力は有料が自然 |

### 3.2 機能振り分け詳細

| 機能 | 無料プラン | プレミアムプラン | 振り分け根拠 |
|------|:----------:|:----------------:|--------------|
| **1Dカット最適化** | 無制限 | 無制限 | コア機能。無料で完全に使えることがDL動機 |
| **SPF材プリセット8種** | 全種利用可 | 全種利用可 | 基本データは制限しない |
| **カスタム木材入力** | 利用可 | 利用可 | 基本操作は制限しない |
| **プロジェクト保存** | **3件まで** | 無制限 | 軽いフリクションで課金動機を作る |
| **カーフ幅設定** | 利用可 | 利用可 | 精度に関わる設定は制限しない |
| **F9: 2D合板カット** | **プレビューのみ** | 全機能利用可 | 最大の差別化機能。体験させて価値を示す |
| **F10: 金額計算** | **基本計算のみ** | 詳細計算+税計算 | 基本は無料、詳細は有料 |
| **F11: PDF出力** | **透かし付き** | 透かしなし | 出力系の制限は自然な課金ポイント |
| **F12: ホームセンターDB** | **SPFカテゴリのみ** | 全カテゴリ | データアクセスの段階制限 |
| **ダークモード** | 利用可 | 利用可 | UIテーマは制限しない（UXの基本） |
| **広告表示** | あり | **なし** | 広告除去は課金動機の定番 |
| **カット図の色分け** | 基本色 | **カスタム色** | 小さな付加価値だが所有欲を刺激 |

### 3.3 各制限の心理学的設計

#### プロジェクト保存: 3件制限

- **エンダウメント効果（保有効果）**: ユーザーは自分が作ったプロジェクトに愛着を持つ。3件目を保存した後、4件目を保存しようとした時に「既存のプロジェクトを削除するか、プレミアムにアップグレードするか」の選択を迫られる。削除の「損失」を避けるために課金する。
- **なぜ3件か**: 1-2件では初回体験が窮屈になりすぎる。5件以上では制限として機能しない。3件は「十分に体験できるが、本格利用には足りない」絶妙な閾値。

#### 2D合板カット: プレビューのみ

- **ツァイガルニク効果**: 未完了のタスクは完了タスクより記憶に残りやすい。2Dカットの「最適化結果のプレビュー」を見せるが、詳細な配置図は見せない。「あと一歩で手に入る」という感覚が購買意欲を高める。
- **具体的な実装**: 2D配置の利用率（%）と必要枚数は表示するが、実際の配置図にはぼかし（ブラー）をかけ、「プレミアムで全体を表示」と案内する。

#### PDF出力: 透かし付き

- **フット・イン・ザ・ドア技法**: まず透かし付きPDFを使ってもらい、PDF出力の便利さを体感させる。その後「透かしなし版が欲しい」→ 課金、という流れ。
- **透かしの内容**: 「板取りくん Free版」と薄く表示。実用上は読めるが、ホームセンターに持っていくにはやや恥ずかしい。社会的プレッシャーが課金を促す。

## 4. 価格戦略

### 4.1 価格設定

| プラン | 価格（税込） | 備考 |
|--------|:------------:|------|
| 無料プラン | ¥0 | 広告あり、機能制限あり |
| **プレミアム（買い切り）** | **¥980** | 広告なし、全機能利用可 |
| ~~プレミアム年額~~ | ~~¥1,480/年~~ | v1.1時点では実装しない（将来検討） |

### 4.2 価格の心理学的根拠

#### ¥980 の合理性

1. **端数効果（Left-Digit Effect）**: ¥1,000ではなく¥980。「千円以下」という認知が購買障壁を下げる。特に日本市場では「ワンコイン〜千円以下」がアプリ課金の心理的上限。

2. **アンカリング**: 以下の参照価格と比較させるコピーで、¥980の割安感を演出する。
   - 「木材1本分の無駄 ¥300〜800 を毎回節約」
   - 「ホームセンター1回のカット代以下で永久に使える」

3. **メンタルアカウンティング**: DIYユーザーは「DIY・ホームセンター費用」の精神的口座を持っている。そこに¥980は容易に収まる。日常の「アプリ課金」口座（上限が低い）ではなく、「DIY材料費」口座（数千〜数万円）に入れてもらう訴求が重要。

4. **競合比較（暗黙のアンカー）**:

   | 競合アプリ | 価格 | 特徴 |
   |------------|------|------|
   | CutList Optimizer | 無料（広告あり） | 1Dのみ、英語 |
   | Cut Optimizer Pro | ¥1,200 | 2D対応、英語UI |
   | MaxCut（デスクトップ） | $50〜 | 業務用、高機能 |
   | **板取りくん** | **¥980** | **日本語、1D+2D、PDF** |

   日本語で2D対応のアプリは希少。¥980は競合と比較して「安いのに日本語で高機能」というポジションを取れる。

### 4.3 プロトタイプ期間の価格設計

```
Phase 0: プロトタイプ（現在〜v1.0リリース後1ヶ月）
  → プレミアム機能も全て無料開放
  → 広告は表示（AdMob SDK の動作検証も兼ねる）
  → 目的: ユーザーフィードバック収集、レビュー獲得

Phase 1: ソフトローンチ（v1.1リリース時）
  → プレミアム機能の制限開始
  → ¥980 での買い切り課金開始
  → 「ローンチ記念 期間限定 ¥480」キャンペーンを実施（後述）

Phase 2: 通常運用
  → ¥980 定価販売
  → 定期的なセール（年2-3回）
```

### 4.4 ローンチ価格キャンペーン

**デコイ効果 + 時間的希少性** を活用した初回キャンペーン:

```
┌─────────────────────────────────────────┐
│  🎉 リリース記念キャンペーン             │
│                                         │
│  プレミアム 通常 ¥980 → 今だけ ¥480     │
│                                         │
│  ⏰ 残り 14日                            │
│  ※ 一度購入すれば永久にプレミアム       │
└─────────────────────────────────────────┘
```

- **時間的希少性（FOMO）**: カウントダウンにより「今買わないと損」を喚起
- **アンカリング**: ¥980（定価）を先に見せることで¥480が割安に感じる
- **目的**: 初期ユーザーの課金率を上げ、レビュー（「¥480でこの機能はお得」等）を獲得

### 5.3 広告配置の詳細

| 画面 | 広告種類 | 配置 | 理由 |
|------|----------|------|------|
| ホーム画面 | AdMob バナー (320x50) | FABの上、リスト下部 | 閲覧時間が長く、操作を妨げない |
| 木材選択画面 | **なし** | - | タップ操作が多く誤タップリスク高 |

### 5.4 インタースティシャル広告について

**v1.1 では導入しない。** 理由:

1. **リアクタンス（心理的抵抗）**: 操作を中断される広告は、ツール系アプリでは離脱率の主因。ストアレビューの低下に直結する。
2. **DIYアプリの利用頻度**: 日常アプリと異なり利用頻度が低い。少ない利用機会でのネガティブ体験は致命的。
3. **バナー + 課金除去で十分**: 軽い不快感（バナー）を課金で解消する設計で収益化できる。

**将来的な検討**: DAUが1,000を超え、課金転換率が安定した段階でリワード広告（任意視聴型）の導入を検討する。例:「動画を見てPDF透かしを1回解除」。

## 6. 課金転換の行動心理学的アプローチ

### 6.1 活用する心理原則の一覧

| # | 原則 | 適用場面 | 倫理的配慮 |
|---|------|----------|------------|
| 1 | 損失回避バイアス | 木材の無駄金額の可視化 | 実際に節約できる金額のみ表示 |
| 2 | アンカリング効果 | 価格表示、節約額との比較 | 虚偽の「元値」は使わない |
| 3 | フット・イン・ザ・ドア | 無料→透かしPDF→課金 | 段階的で自然な導線 |
| 4 | エンダウメント効果 | プロジェクト保存制限 | 削除ではなく「保存できない」制限 |
| 5 | ツァイガルニク効果 | 2Dカットのプレビュー | 完全にブロックせず「見せて止める」 |
| 6 | 社会的証明 | レビュー・利用者数の表示 | 実際の数値のみ使用 |
| 7 | 希少性・FOMO | ローンチ価格キャンペーン | 実際に期間限定であること |
| 8 | ピーク・エンドの法則 | 計算結果表示時のアップセル | 成功体験の直後に訴求 |
| 9 | デコイ効果 | 将来的な複数プラン提示時 | 現時点では2択のため保留 |
| 10 | 認知的不協和 | 「本気のDIYer」アイデンティティ | 煽りではなく共感ベース |

### 6.2 課金転換ジャーニー

ユーザーが自然に課金に至るまでのストーリーを設計する。

```
Day 0: インストール〜初回利用
────────────────────────────
 ・1Dカット最適化を完全無料で体験
 ・「購入: 3本 → 2本に削減！¥600節約」と具体的な節約額を表示
 ・プロジェクト保存（1件目）: スムーズに成功 → 満足感
 ・結果画面下部: 小さく「プレミアムで広告非表示＆PDF出力」

Day 1〜7: 2回目利用
────────────────────────────
 ・別のプロジェクトで再利用（リテンション成功）
 ・プロジェクト保存（2件目、3件目）: まだ余裕がある
 ・2D合板カットを試す → プレビュー表示 → 「もっと見たい」欲求
 ・PDF出力を試す → 透かし付きで出力される → 実用性を体感

Day 7〜30: 制限への遭遇
────────────────────────────
 ・プロジェクト4件目 → 保存制限に遭遇
```

**実装詳細**:
- F10（金額計算）が有効な場合のみ表示
- 単価が未入力の場合は非表示（虚偽の数値は出さない）

#### (6) ピーク・エンドの法則: 最適なタイミングでの訴求

人は体験全体ではなく「ピーク時」と「終了時」の印象で体験を評価する。

**ピークポイント = 計算結果表示の瞬間**

計算結果が表示された直後（「おお、2本で済むんだ！」の瞬間）は、アプリへの好感度が最も高い。このタイミングで:

```
計算結果表示
  ↓ （ユーザーの満足度が高い）
サマリー確認
  ↓
カット図確認
  ↓ （ここまでは邪魔しない）
スクロール末尾に到達
  ↓
「もっと便利に使いませんか？」
  プレミアムの小さなバナー表示
```

**重要**: 結果表示直後にポップアップを出すのはNG（ピーク体験を阻害）。結果を十分に見た後、自然にスクロールで到達する位置に配置する。

## 8. 将来的なサブスクリプション化の検討

### 8.1 現時点で買い切りを選ぶ理由

| 要因 | 判断 |
|------|------|
| ユーザーの利用頻度 | 月1-2回が主流 → サブスク価値を感じにくい |
| サブスク疲れ | 日本市場でアプリサブスク疲れが顕著 |
| 競合状況 | DIYアプリで月額課金は一般的でない |
| LTV | 買い切り¥980 vs 月額¥200×6ヶ月＝¥1,200。離脱率を考慮すると買い切りの方が回収確実 |
| ストアレビュー | サブスクは低評価レビューの原因になりやすい |

### 8.2 サブスクリプション移行の条件

以下の **全て** が満たされた場合にサブスク導入を検討する。

| # | 条件 | 指標 |
|---|------|------|
| 1 | 継続的に更新される価値がある | ホームセンターDB の月次更新、木材価格の自動反映 |
| 2 | 月間アクティブユーザーが安定 | MAU 5,000人以上 |
| 3 | リテンション率が十分 | D30リテンション 30%以上 |
| 4 | ユーザーからの要望 | 「もっと頻繁にアップデートしてほしい」の声 |
| 5 | 運用コストの発生 | サーバーサイドDB、APIなどのランニングコスト |

### 8.3 サブスク導入時の想定プラン

**導入する場合**、既存の買い切りユーザーは永久にプレミアム（Grandfather条項）とする。

| プラン | 月額 | 年額 | 対象 |
|--------|------|------|------|
| 無料 | ¥0 | ¥0 | 現行の無料プラン |
| プレミアム（月額） | ¥300 | - | ライトユーザー向け |
| プレミアム（年額） | - | ¥1,980 | 45%オフ（デコイ効果で年額を魅力的に見せる） |
| 買い切り | ¥2,980 | - | サブスクを嫌うユーザー向け（アンカーとしても機能） |

**デコイ効果の活用**:
- 月額¥300 × 12 = ¥3,600/年
- 年額 ¥1,980/年 → 45%オフに見える
- 買い切り ¥2,980 → 年額1.5年分。2年以上使うなら買い切りがお得

3つの選択肢により、ユーザーは「年額がお得」と感じやすくなる（デコイ効果）。ただしこれはあくまで将来の検討であり、v1.1時点では買い切り一択とする。

```
  ┌────▼────┐    ┌────▼────┐
```

- **キャッシュ**: Hive にプレミアム状態を保存（オフライン対応）

## 付録A: 倫理ガイドライン

本戦略で **行わないこと** を明示する。

| Dark Pattern | 説明 | 対策 |
|-------------|------|------|
| **Confirmshaming** | 「課金しない = ダメな選択」と感じさせる | キャンセルボタンに中立的な文言（「あとで」「閉じる」） |
| **Hidden costs** | 後から追加料金を請求 | 買い切りは買い切り。追加請求なし |
| **Forced continuity** | サブスクの自動更新を分かりにくくする | 現時点でサブスクは導入しない |
| **Roach motel** | 課金は簡単、解約は困難 | 「購入を復元」ボタンを常に表示 |
| **Fake urgency** | 嘘のカウントダウン | キャンペーンは実際に期間限定。終了後は通常価格に戻す |
| **Fake social proof** | 架空のレビューや利用者数 | 実数のみ使用。数値がない段階では非表示 |
| **Nag screen** | しつこいポップアップ | 制限に遭遇した時のみ1回表示。同セッション内で繰り返さない |
| **障壁の意図的追加** | 無料ユーザーにわざと不便を強いる | 無料機能は快適に動作させる。制限は機能の「不在」であり「劣化」ではない |
