**問題:** screenshot-5-flow.svg は viewBox が `0 0 1290 2796` で iPhone 6.7" サイズとしては正しいが、このスクリーンショットはデバイスフレーム付きの画面キャプチャではなく、フロー紹介用のマーケティング画像である。Apple App Store のスクリーンショット要件では「アプリの実際のスクリーンショット」が求められるため、この画像がスクリーンショットとして提出される場合は問題となる可能性がある。

- あるいは、screenshot-1 ~ screenshot-4 のような実アプリ画面をベースとしたデバイスフレーム付きの構成に変更する

## 6. 修正必須項目 (FAIL)

### FAIL-001: スクリーンショット5のストア提出適合性

**ファイル:** `assets/screenshots/screenshot-5-flow.svg`
**問題:** Apple App Store のスクリーンショットガイドラインでは、実際のアプリ画面を反映したスクリーンショットが求められる。screenshot-5 はマーケティング用フロー紹介画像であり、デバイスフレーム内のミニ画面は含まれているが、実際の1画面のスクリーンショットではない。
**影響度:** 中（Apple 審査リジェクトの可能性）
**修正提案:**
1. Apple 提出時は screenshot-1 ~ screenshot-4 の4枚のみを使用する
2. Google Play ではプロモーション的スクリーンショットが許容されるため、screenshot-5 を含めてもよい
3. 代替案として、設定画面やプロジェクト詳細画面のスクリーンショットを追加する

### FAIL-002: アイコンタグラインのコントラスト不足

**ファイル:** `assets/app-icon.svg`
**問題:** テキスト「木材カット最適化」(font-size: 32px, fill: #FFFFFF, opacity: 0.6) は木目背景 (#8B6914 ベース) に対してコントラスト比が約 2.0:1 で、WCAG 2.1 AA の通常テキスト要件 4.5:1 を大幅に下回る。
**影響度:** 低（アイコン内テキストは装飾的要素と見なせるケースもある）
**修正提案:**
```xml
<!-- 変更前 -->
<text ... fill="#FFFFFF" ... opacity="0.6" letter-spacing="2">

<!-- 変更後 (opacity を 0.85 以上に) -->
<text ... fill="#FFFFFF" ... opacity="0.85" letter-spacing="2">
```

### REC-003: Android アダプティブアイコン専用素材
現在のアイコンから以下のレイヤーを分離して準備することを推奨:
- foreground: 木材ボード + カット線（テキストなし）
