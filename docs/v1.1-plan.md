# 板取りくん v1.1 開発計画

> 作成日: 2026-02-28
> ベースバージョン: v1.0 (MVP)
> 目標: ユーザー価値の大幅向上 + 収益化基盤の構築

---

## 概要

v1.0 では1D（長さ方向のみ）のカット最適化を実現した。
v1.1 では **2D合板カット対応**、**PDF出力**、**コスト計算** を柱に、
実用性を大きく引き上げてストアレビュー向上・課金導線の確保を目指す。

---

## 新機能一覧

### F9: 2D合板カット最適化（優先度: 高）

**概要**: 合板（ベニヤ・MDF等）を対象に、縦×横の2次元でカット配置を最適化する。

**ユーザーストーリー**:
- DIYユーザーとして、合板から複数の板を切り出すとき、最も無駄が少ない配置を知りたい

**仕様**:
- 合板サイズ入力（プリセット: 3x6判 910×1820mm、4x8判 1220×2440mm、サブロク等）
- カスタムサイズ入力対応
- 部材は矩形（幅×高さ）で指定、数量指定可能
- 回転あり/なし 設定（木目方向を考慮）
- 2D ビンパッキングアルゴリズム（Guillotine Cut / Shelf アルゴリズム）
- 視覚的な2Dカット図（上から見た配置図）

**技術タスク**:
- [ ] 2D ビンパッキングアルゴリズムの選定・実装
  - Guillotine Cut（ギロチンカット）: 実際の合板カットに近い制約
  - 回転対応ロジック
- [ ] 合板プリセットデータ作成（`data/plywood_presets.dart`）
- [ ] 2D カット図 CustomPainter 実装（`widgets/cut_diagram_2d.dart`）
- [ ] 合板選択画面の追加 or 木材選択画面の拡張
- [ ] 部材入力画面に幅フィールド追加（2Dモード時）
- [ ] 結果画面の2D表示対応
- [ ] モデル拡張（`PlywoodStock`, `RectPiece` 等）
- [ ] ユニットテスト追加（2Dアルゴリズム用）

**工数目安**: 大（アルゴリズム + UI 両方の実装が必要）

---

### F10: 金額計算（優先度: 中）

**概要**: 木材の単価を入力し、必要本数から合計金額を自動算出する。

**ユーザーストーリー**:
- DIYユーザーとして、必要な木材の合計費用を事前に把握し、予算内で計画を立てたい

**仕様**:
- 木材選択画面に単価入力フィールド追加（税込/税抜切り替え）
- 結果画面に費用サマリー表示:
  - 必要本数 × 単価 = 合計金額
  - 端材が出た場合の実質コスト（利用率ベース）
- プリセット木材に参考価格を付与（任意、ユーザー上書き可能）
- 消費税率設定（設定画面、デフォルト10%）

**技術タスク**:
- [ ] `WoodStock` モデルに `unitPrice` フィールド追加
- [ ] 木材選択画面に単価入力UI追加
- [ ] 結果画面にコストサマリーウィジェット追加
- [ ] 設定画面に消費税率設定追加
- [ ] プリセットデータに参考価格追加（任意）
- [ ] `CutResult` にコスト計算メソッド追加

**工数目安**: 小〜中

---

### F11: カット指示書PDF出力（優先度: 高）

**概要**: 最適化結果をPDFとして出力し、印刷してホームセンターや作業場で参照できるようにする。

**ユーザーストーリー**:
- DIYユーザーとして、カット図をPDFで印刷し、ホームセンターのカットサービスに渡したい

**仕様**:
- PDF内容:
  - プロジェクト名・作成日
  - 使用木材情報（種類・長さ・本数）
  - カット図（1D / 2D 対応）
  - 部材一覧表（ラベル・長さ・数量）
  - 利用率・端材情報
  - 金額サマリー（F10が有効な場合）
- A4縦/横 自動レイアウト
- 共有機能（iOS: Share Sheet / Android: Intent）

**技術タスク**:
- [ ] `pdf` パッケージ導入（pubspec.yaml）
- [ ] `printing` パッケージ導入（印刷・共有機能）
- [ ] PDF生成サービス実装（`services/pdf_generator.dart`）
- [ ] カット図のPDF用レンダリング（Canvas → PDF変換）
- [ ] 結果画面に「PDF出力」ボタン追加
- [ ] プレビュー画面実装
- [ ] 日本語フォント埋め込み対応

**工数目安**: 中

---

### F12: ホームセンター木材DB（優先度: 低）

**概要**: 主要ホームセンターで取り扱いのある木材データベースを拡充する。

**仕様**:
- カテゴリ別木材一覧（SPF, 杉, 檜, 合板, 集成材 等）
- サイズ・参考価格の一覧表示
- 検索・フィルター機能
- 将来的にはオンラインDB連携（API）も検討

**技術タスク**:
- [ ] 木材データベース設計（JSON or Hive）
- [ ] 木材カテゴリ・データ収集
- [ ] 木材一覧画面実装
- [ ] 検索・フィルターUI
- [ ] 木材選択画面との連携

**工数目安**: 中（データ収集が主なコスト）

## 開発優先順位

```
Phase A: コア機能（リリース必須）
  1. F10 金額計算        ← 実装が軽く効果大
  2. F11 PDF出力         ← ユーザー要望が高い
  3. ダークモード        ← ストア審査で好印象

Phase B: 差別化機能
  4. F9  2D合板カット     ← 最大の差別化要素、工数大
  5. cm単位サポート

Phase C: 基盤強化
  6. Firebase Crashlytics
  7. AdMob 導入（Phase 0 基盤は実装済み → Phase 1 で本番化）

Phase D: データ拡充
  8. F12 ホームセンターDB
```
